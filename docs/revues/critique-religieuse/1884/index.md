## ERRATA. {#errata}

Page 117, *après* le paragraphe commençant par ces mots : renoncer au monde, à la vie terrestre, *reportez* le long passage qui commence, page 118, par ces mots : Pour l'amener à rompre, et qui va, page 119, jusqu'au paragraphe commençant par ces mots : Ainsi résumée toutefois.

Page 126, ligne 34, *au lieu de* : parce qu'ils voulaient se contenter des inspirés, *lisez* : parce qu'ils ne voulaient prendre pour guides que des inspirés.
